## 2. 实验条件（README「Methodological Information」原文摘编，这是可比性的全部前提）

| 量 | 值 | 对仿真的含义 |
|---|---|---|
| 机器 | EOS M290（NIST Gaithersburg） | 商用机，光斑/波动特性未公开 ⇒ 只能标称对照 |
| 基板 | **76 × 76 × 6 mm 镍基 625 实心板**，beam-on-plate | **没有粉末层**！传热是体材料散热主导；我方链**不许**挂 `powder/powderbed` 档 |
| 激光功率 | 285 W（厂商推荐参数） | 固定输入 |
| 扫描速度 | **960 mm/s** | 与 `singleTrack.csv` 时间戳自洽：2 mm / 2.08 ms = 961.5 mm/s |
| 搭接间距 | 110 µm | 多道几何 |
| skywriting | **开启**（到道末端关光，加减速后才在下一道重新开光） | 关光间隙必须进驱动，否则热积累曲线整体偏乐观 |
| 构型 | 18 道**等腰梯形**快速折返（converging 从宽端起 / diverging 从窄端起） | 面积随道号变化 ⇒ 能量输入率随道号漂移，正是瞬态考核点 |
| 取样方式 | 每个试件只扫到第 N 道（N=1…18）后**提前停止**，得到"冻结快照"；测**最后一道**的熔池 | **对比的是"扫到第 N 道时最后一道的熔池"**，不是同一件上连续 18 道 ⇒ 复现必须逐 N 重跑，不能一次跑完取尾 |
| 测量 | Zeiss AxioImager.Z2 亮场顶面像，两位操作员用 ImageJ 描内折线边界；量**最大熔池宽**与**顶面面积** | 顶面熔池几何，非截面 ⇒ 我方输出的等温面与顶面交线要按同一定义取 |
| 重复 | Set 2 每组 3 次重复（D1/D2/D3、C1/C2/C3）；Set 1 只有部分道号有值 | **操作员间散差**是现成的不确定度来源，偏差判定必须带上它 |

## 3. 数据表结构（`Measurements.xlsx` / Sheet1，用 stdlib zip+xml 解析，无 openpyxl）

- `Set 1 / Operator 1`：列 D（Diverging 宽）、E（Converging 宽）、F（Diverging 面积）、G（Converging 面积），
  仅道号 **2–8、18** 有值；宽 212–331 µm、面积 169142–283653 µm²。
- `Set 2 / Operator 1`（列 I–N 宽、O–S 面积）与 `Set 2 / Operator 2`（同列位）：道号 **1–18 全**，
  每组 3 个重复（D1/D2/D3、C1/C2/C3）。宽 129–460 µm、面积 82084–315236 µm²。
- 表末 `S=Outliers` 标注行存在 ⇒ **离群值已由作者标出**，取均值前须照其排除，不许自定阈值。

## 4. 为什么这个靶子值得跑（不是"随便找个公开数据"）

1. 它考核的正是我方**本轮 A0 声称的能力**：物理曝光时长 + 关光间隙 + 真实潜热下的**瞬态热积累**
   （宽度随道号 1→18 单调上升到饱和的曲线形状），粗网格/准稳态类模型**造不出这条曲线**。
2. `singleTrack.csv`（285 W / 960 mm/s / 2 mm 单道）给出**同批次的单道基线**，可与
   AMB2018-02 的单道互为佐证。
3. 两个操作员的重复给出**实测不确定度**，使"偏差 >20% 就算未达商业级"这类判据有分母可依。

## 5. 下一步（任务 #10 的 S3 判据草案，跑前登记）

- 材料卡：用仓库 `materials.py:306-312` 的 IN625（注释已声明其为 NIST AM-Bench 基准材料而存在）；
  **须先核对其物性来源与温度相关项**，与 625 常见牌性对照后记录差异。
- 几何：实心板而非粉床 ⇒ 域取板厚 6 mm 全部 + 侧向足够深的热影响区；边界按 README 未给对流系数
  ⇒ 需自建辐射/对流口径并做敏感性，**这条是偏差的合法来源，必须量化而非隐去**。
- 档位：标定档（dx ≤ r/2、真实曝光、skywriting 关光间隙）。
- 判据（先登记再跑）：① 单道宽度与实测的相对偏差 + 操作员散差；② 1→18 道宽度**曲线趋势**（单调性、
  饱和位置）而非单点；③ 顶面面积偏差；④ 若偏差 >20%，照实在日志写"标定档尚未达商业级"。
- 代价预警：§25.7 成本律下，18 道 × 960 mm/s 在标定档 dx 上的 voxel-step 可能很高；
  **先用 3 道（N=1,2,3）做可行性与偏差量级，再决定是否全量**，不许未登记代价就开全量。
