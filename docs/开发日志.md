## 0. 项目背景与最终目标

用户拟开发一款增材制造模拟软件，核心定位是**对增材全流程进行真实物理模拟**（区别于纯代理/经验近似），并具备可微分优化能力。经多轮澄清，最终需求收敛为三大真实模拟 + 一项优化能力：

| 域 | 要求 |
|---|---|
| **① 宏观成型过程模拟** | 真实三维复杂构型的 AM 成型（SLM 激光选区熔融 + LSF 激光立体成型）；充分多物理场 + **固液/液固相变**；**FVM、FEM、DEM、SPH、MPM 五种数值方法都需具备** |
| **② 微观模拟** | 相场法（Phase Field）+ 晶体塑性有限元（CPFE）；由增材工艺推断材料本构（工艺参数 → 宏观力学性能本构） |
| **③ 数字样机** | 基于「FEM + 多体」混合仿真：增材件本体用 FEM 算强度/残余应力（精度），周边/机构部件用多体动力学（MBD）算运动/接触（速度），二者协同耦合 |
| **④ 可微分模拟** | 在上述计算基础上，对制造工艺参数求梯度、反向修正，迭代优化直至收敛 |

**通用性要求**（后期补充）：最终要成为商业软件形态——可靠好用的 GUI（类 Abaqus：导入模型/网格/粒子、便捷处理边界与初始条件等前处理）+ 便捷 API（积木式快速建模）。GUI 技术栈定为 **PySide6 + VTK（Python 原生桌面）**，多体定为**真多体动力学 + FEM 混合协同**。

参考背景文件：
- `am-feasibility-assessment.html.zip`（可行性评估）
- `整合JAX软件资源开发计算力学软件.zip`（含 `diffmech` 计算力学资源，已落于 `src/diffmech/`）

## 1. 架构演进路线

整个开发在"代理级快速验证 → 发现真实引擎 → 战略 pivot → 通用引擎地基"的脉络中推进。

### 1.1 第一版：amforge 代理级 9 契约管线（已闭合）
设计统一数据契约 + 求解器注册表 + DAG 编排器，把四大功能实现为可无缝链接的求解器：
- **9 个 frozen dataclass 契约**（全注册为 JAX pytree，是模块间唯一通信语言）：
  `PartGeometry → ProcessPlan → ThermalHistory → MeltPoolResult → MicrostructureResult → ConstitutiveField → AsBuiltPart → StructuralResult → ServiceVerdict`
- **求解器注册表 + `Pipeline.auto` 反推选路**：`register_solver(name, consumes, produces, stage, modality, differentiable, cost, ...)`；`Pipeline.auto(target, modality)` 反向链式选路，`pipe.run(**inputs)` 实跑，`pipe.function` 柯里化供 `jax.grad`/`jax.jit`。

### 1.2 第二版：发现 diffmech 真实引擎（战略转折点）
仓库内 `src/diffmech/` 是一套**独立的 JAX 计算力学套件**，远超 amforge 的解析代理。其 AM 子模块与 8 类数值方法，已在 smoke 测试中实证可跑三维逐层热-力 FEM。

### 1.3 第三版：ForgeCore 通用引擎（当前地基）
把编排层泛化为与物理域解耦的通用引擎 `src/forgecore/`，amforge 的 9 求解器作为"适配层"注册进去。核心设计原则：**单一 canonical 模型对象 + 双前端（GUI / Python API）+ 求解器注册表**——GUI 与脚本产出完全一致的 `.amf` 工程文件；同一张图既能正向跑仿真，也能整体求梯度；新增物理/方法只需"加积木 + 注册求解器"，核心永不硬编码某种数值方法。这是通用性的根基。

### 里程碑 M3：修复功能②训练 NaN（可微闭环打通）★关键
**现象**：`train_process_predictor` 第一步 loss=0.82（有限），第二步变 NaN。
**定位方法**（"按损失分量 → 按输出张量"两步 bisect）：
1. `_scratch/debug_buildup.py` 逐输出 bisect → 锁定 `von_mises_residual` 梯度 NaN（其余输出 clean）。
2. 根因：`AsBuiltPart.von_mises_residual()` 用 `jnp.sqrt(...)`，当残余应力=0 时 sqrt 参数=0，逆向 `1/(2√x)→∞`，经 `0·NaN=NaN` 污染全链。
3. 修 `jnp.sqrt(jnp.maximum(arg,0.0)+1e-30)`（3D/2D 两分支）。
4. 重跑训练**仍 NaN（第 4 步）**——发现第二处同源 bug：`inverse.loss_fn` 等效应变项 `sqrt(Σ应变²)` 在零应变体素炸梯度，同样加 `1e-30`。
5. 全局 grep `jnp.sqrt(` 排查其余潜在点。
**结果**：`train_process_predictor` 损失 **0.82 → 0.37（2.2× 下降）**，verdict=**PASS（强度安全系数 1.91）**，梯度全程有限、非全零。**功能②可微闭环真正兑现**。

### 里程碑 M6：能力对照与战略 pivot（用户澄清主目标）
用户明确"要做**真实模拟**，不是代理近似"。经 grep + smoke 实测，盘点 diffmech 真实现状与缺口：

| 要求 | diffmech 现状 | 成熟度 |
|---|---|---|
| ① FVM 热（含相变） | 纯热扩散 `diffusion_rhs`，**无潜热/相变** | ⚠️ 缺口 |
| ① FEM 热-力 | `solve_thermomechanical` 已实测跑通，但仅线弹性、无塑性 | ✅ 可用/待补 |
| ① DEM/SPH/MPM | `particle_am` 含 solidus/liquidus/solidification（粉末尺度，最接近 Flow3D） | ✅ 模块齐/待端到端验证 |
| ① SLM + LSF | `process.py` SLM/LSFConfig；扫描路径 zigzag/contour/spiral + gcode/csv | ✅ 已有 |
| ① 多物理+相变 | 相变只在粉末(particle_am)与微观(am_microstructure)路径，**连续介质热解无相变** | ⚠️ 缺口 |
| ② 相场法 | 通用 Allen-Cahn/Cahn-Hilliard，**非 AM 专用凝固**（无枝晶/各向异性/热梯度耦合） | ⚠️ 半成品 |
| ② CPFE | `cpfe_solver` 完整（滑移系/累积滑移/硬化/塑性力装配），voigt/reuss 上采样存在 | ✅ 可用 |
| ② 工艺→本构 | `am_microstructure` + CPFE + 上采样路径基本齐备 | ✅ 主线可连 |
| ③ FEM 强度校核 | thermomechanical + load_cases | ✅ 可用 |
| ③ 多体动力学 | **完全缺失**（全库无 joint/rigid/assembly 模块） | ❌ 最大缺口 |
| ④ 可微优化 | `optimize/inverse.py`（Optax Adam+GD, jit-able）+ `am_api.am_loss_and_grads` | ✅ 基础设施齐备 |

**战略结论**：保留 amforge 9 契约"无缝链接"框架作**编排层**，但默认求解器须改接 diffmech 高保真；代理只作快算回退。真实缺口 4 条：① 连续介质热解补潜热/相变(enthalpy 法)；② 新建多体数字样机；③ 相场 AM 专用化；④ 可微优化从高保真链反传。

## 3. 关键技术决策一览

| 决策点 | 结论 | 理由 |
|---|---|---|
| 统一数据契约 | 9 个 frozen pytree dataclass 作模块唯一通信语言 | 保证"无缝链接"、可序列化、可微 |
| 编排机制 | 求解器注册表 + DAG 反推选路 `Pipeline.auto` | 新增方法=加积木+注册，核心不硬编码 |
| 可微来源 | 纯 JAX 函数 + `jax.grad`/`jax.jit` 穿透整图 | 正向仿真与梯度优化共用同一张图，"免费"可微 |
| 代理 vs 高保真 | 9 契约框架保留；默认求解器改接 diffmech 高保真，代理作快算回退 | 兑现"真实模拟"，同时保留设计反演速度 |
| GUI 技术栈 | **PySide6 + VTK（Python 原生桌面）** | 类 Abaqus 体验、本地高性能、Python 兼容、可拓展 |
| 多体范围 | **真多体动力学 + FEM 混合协同** | 增材件本体 FEM 保精度，周边/机构 MBD 保速度 |
| 工程文件 | `.amf`（JSON，几何/材料用重建描述而非内联张量） | GUI 与脚本产出完全一致，便于版本管理与重跑 |

## 7. 关键经验与可复用资产

- **JAX 可微链 NaN 定位法**（已沉淀为 skill `jax-gradient-nan-debug`，用户级，已校验打包）：
  1. 前向 loss 有限但梯度 NaN ⇒ 必有 `sqrt/log/arcsin(可=0)` 或 `1/x(可=0)`；
  2. bisect 顺序：**先按损失分量求 grad**（定位是哪个 term），**再按输出张量求 grad**（定位是哪个 output）；
  3. 标准修法：给参数加非负下界 epsilon `jnp.sqrt(jnp.maximum(x,0)+1e-30)`；
  4. 警惕 `0 * NaN = NaN` 硬掩膜陷阱（mask 应在 NaN 产生**之后**乘，或让掩膜前的值先有限化）。

## 8. P2-① 热解潜热相变（enthalpy 法）实现完成

> 状态：✅ 已落地 + 6 项测试通过（并入全量 37 项，0 失败）
> 时间：2026-08-12（延续第 7 节末尾"先啃 P2-①"的排期）

### 8.1 动机
既有 `thermal.history`（代理）按逐道熔池半解析累积零件级热历史，**不含固-液-固相变潜热**，
无法呈现熔池凝固的"温度平台 / 潜热吸收"真实物理。P2-① 用 **enthalpy 法（Voller & Prakash）**
补齐这一缺口，作为 9 契约链中 `thermal` 端口的高保真可选项。

### 8.2 核心设计
- **状态变量取焓** `H [J/m³]`：`H(T) = ρ·c_p·(T−T_amb) + ρ·L·f(T)`，
  `f(T)=smoothstep(T; T_solidus, T_liquidus)` 为平滑液相分数（mushy 区 df/dT ≥ 0）。
- **变系数 FVM `∇·(α_H ∇H)`**：`α_H = k / (ρ·c_p + ρ·L·f'(T))` —— mushy 区有效扩散率被潜热压低，
  自然产生温度平台（潜热吸收），无需硬切换界面。Neumann（绝热）边界用 ghost/concatenate 实现。
- **T(H) 逆映射用二分法（非 Newton）**：H(T) 严格单调，对 `[T_amb, T_amb+(H+ρL)/(ρc_p)]` 二分 24 步，
  全程可微、无振荡（Newton 在 f'≈0 处会 2-cycle 振荡，误差 56K → 二分 0.018K）。
- **移动高斯热源**：面内 `ρ²` 与层厚 `z²` 分离的体积源；线能量密度 `P/v` 通过 `Q0 ∝ clip(v_ref/v,0.3,3)`
  进入可微链——扫描速度↑ ⇒ 沉积能量↓ ⇒ 峰值温度↓，**梯度 wrt. scan_speed 有限且非零**。
- **SSP-RK2（Heun）时间积分**置于 `jax.lax.scan` 内，端到端可微；同时追踪峰值温度、冷却率、
  高于熔点的时间、温度梯度 `G=|∇T|`、凝固速率 `R=cool/G`。

### 8.3 接入 ForgeCore
- `src/forgecore/registry.py` 的 `auto/build/required_inputs` 新增 `select` 形参：
  `select={"thermal":"thermal.enthalpy"}` 强制该端口解析到指定求解器。
- `src/amforge/forge_adapter.py` 注册 `thermal.enthalpy`（consumes `("geometry","process")`，
  produces `"thermal"`，modality SLM/LSF，tags `high-fidelity,phase-change`）。默认轻量链路仍走
  `thermal.history`，高保真经 `select` 显式切换，互不干扰。

### 8.4 验证（tests/test_enthalpy_thermal.py，6 项）
1. `liquid_fraction` 单调且 mushy 区有界；2. `temperature_of_enthalpy` 逆映射误差 0.018K；
3. **潜热降低峰值温度**（有 L：2568K < 无 L：2929K）；4. 求解器产出有限 ThermalHistory；
5. **梯度穿透有限且非零**（scan_speed 真正影响热历史）；6. 接入 ForgeCore 且 `select` 可切换
   （`thermal.enthalpy` 在链、`thermal.history` 不在）。
全量回归：`37 passed in ~117s`。

### 8.5 关键坑（已规避）
- **网格分辨率**：光束半径(60–100µm) < 体素(100µm) 且扫描仅采 3 个 x 点 ⇒ 每个体素只热 1 步、不熔化。
  修复：扫描路径改为间距 ≈ dx/2 的连续 zigzag 采样 + 可分辨网格(dx=50–80µm, r=100µm) + 抬高激光功率。

## 9. P2-② 高保真塑性 / CPFE 生死单元 FEM 成形完成

> 状态：✅ 已落地 + 15 项测试全通过（7 项核心求解器 + 8 项 ForgeCore 桥接）
> 时间：2026-08-12（接续 P2-① 之后；用户指定"继续开发 P2-② FEM 塑性/CPFE"）

### 9.1 动机
既有 `asbuilt` 端口默认走 `buildup.layer_activation`（趋势代理，残余应力直接由代理公式给，
**不含真实弹塑性**）。P2-② 用**逐层激活的生死单元弹塑性有限元 + 返回映射**补齐 9 契约链中
`asbuilt` 端口的高保真可选项，让残余应力/应变来自真实物理（J2 各向同性硬化 或 速率相关晶体塑性
CPFE），并经 ForgeCore `select` 显式启用，不破坏默认降阶链路。

### 9.2 核心设计（src/diffmech/methods/am/thermomechanical_plastic.py）
- **生死单元 + 弹性平衡 + 返回映射**：沿用激活门控刚度 `assemble_activated_stiffness`
  （软粉末 α→0 无刚度，系统良态），每个单元中心做率无关返回映射；塑性状态经
  `jax.lax.scan` 跨层携带 → 残余应力、塑性应变、位移均为工艺参数的**一个可微函数**。
- **两种本构**：
  - **J2（von Mises）各向同性硬化**：`J2Plasticity(E,nu,sigma_y0,H=hardening_sat·hardening_rate)`，
    状态 `(ε_p, α)`；越过屈服面后返回映射把应力松弛回屈服强度附近。
  - **CPFE（速率相关晶体塑性）**：`CrystalPlasticity(E,nu,slip_dirs,normals,gamma_dot0,m,g0,h0,g_sat)`，
    过 `n_sub_cp` 子步 `jax.lax.scan` 积分；**过冲护栏** `|dγ| ≤ 0.5·|τ|/(3μ)`（率无关极限）
    让应力松弛*到*晶体屈服面而不跨系过冲/回弹；状态 `(ε_p, γ, g)`。
- **累积冷却加载（本会话关键修正）**：层步 k 的热载荷 = 所有**已沉积**单元（α>0.5）的
  *完整*收缩量 `dT_total = Σ_l eps_th[l]`，而非仅当前层。这样最终残余应力是准静态冷却应力
  （最约束区量级 ≈ E·α·ΔT，即塑性必须封顶的量级），而不是"只有最后一层贡献"。
- **只在几何内出生（element birth only inside part）**：`cell_mask`（体素占用）乘到激活上；
  被掩掉的单元（粉末/空腔）不仅无刚度，其**报告残余应力显式清零**（避免被相邻激活单元经共享
  节点拖拽出伪应力）——真正"只在零件内部出生"。

### 9.3 体素↔FEM 桥接（src/amforge/asbuilt_plastic.py）
- `solve_asbuilt_plastic(*, geometry, thermal, params) → AsBuiltPart`，注册名
  `asbuilt.thermomechanical_plastic`。
- **体素→FEM**：覆盖整张栅格的结构化 hex8 `LayeredMesh`（`nx=Nx-1, ny=Ny-1,
  nz=n_layers·cells_per_layer`）；最近邻 gather 把 `occupancy` 与 `peak_temperature`
  采样到单元中心；`dT_cells = α_T·(peak_T − T_ref)`；逐层热应变 `= dT_cells·onehot(layer_id)`。
- **本构解析**：`get_material` 取料（默认 316L）；`constitutive` 选 `"j2"` 或 `"cp"`
  （按晶格选滑移系：bcc→{110}<111>，其余→fcc {111}<110>）。
- **边界**：基板（z=zmin 面）全约束 `DirichletBC.fixed`；`n_sub_cp=256`。
- **FEM→体素回填**：Voigt(6) 残余应力、塑性应变、单元平均位移 1:1 回填；变形后 SDF
  `= sdf + Σ(vx_disp·n_hat)`（`n_hat` 用 `stop_gradient`，保持几何梯度可微性）。

### 9.4 接入 ForgeCore（src/amforge/forge_adapter.py）
- `register_fn("asbuilt.thermomechanical_plastic","asbuilt",("geometry","thermal"),
  fn=solve_asbuilt_plastic, cost=4.0, 不声明 modality（保持通用），
  tags=("high-fidelity","elasto-plastic","cpfe"))`。
- **关键**：注册时**故意不写 modality**。ForgeCore 的 `_match` 在 `modality="SLM"` 下会优先返回
  命中 modality 专属的求解器——若我方写上 `("SLM","LSF")`，它就会在默认链路里**顶替**
  `buildup.layer_activation`（成本 4.0 > 3.0 但 modality 命中胜出），对 `n_grid=20` 的 e2e
  直接 OOM（17.5 GB）。保持通用后，`_match` 无专属命中、回退全部候选，`_select` 按成本取最小的
  `buildup.layer_activation`，默认链路零改动。
- `auto("verdict", select={"asbuilt":"asbuilt.thermomechanical_plastic"})` 强制选路；
  默认链路仍走 `buildup.layer_activation`（`test_auto_wiring_reaches_verdict` /
  `test_default_chain_unchanged` 守护）；`required_inputs` 仅返回 `["geometry"]`

  → `optimize_dimensional` 内用 **plain `jax.value_and_grad`**（不 jit 外层），几何保持具体，
  内层 FEM 的 jit 按张量形状缓存一次即可；实测 10 步优化 ~2 min（小几何 9³ 体素 / 8³ FEM）。
- **初值要物理合理**：优化器初值用 `heuristic_plan`（几何感知、锁传导工艺窗口），避免从随机
  工艺出发落入未熔合/匙孔病态区导致仿真崩溃或梯度爆炸；测试里再用"偏高能量"工艺作显式劣初值
  以留出优化空间。
- **默认链路零改动**：`asbuilt_solver` 默认 `"buildup"`，`tests/test_dimensional_optimization.py
  ::test_default_simulate_still_buildup` 守护"默认仍走降阶模型、不触发高保真 FEM"。

### 10.4 验证（5 项，全通过）

## 11. 几何/形状优化（反变形 / 预补偿）—— 把尺寸优化从"工艺"升级到"几何"
### 11.1 动机
`optimize_dimensional`（§10）把设计变量定在**工艺参数**（激光功率/扫描速度/…）。
真正的"尺寸优化"应直接优化**零件几何本身**：给定目标 CAD 构型，求一个**名义
（预变形）几何** `sdf_nominal = target.sdf + delta`，使其经增材成形后的实际构型
（as-built）尽量贴合 target——即增材领域的**反变形 / 预补偿**（distortion compensation）。

关键使能：高保真 `AsBuiltPart.sdf = nominal_sdf + disp·n̂` 中 `nominal_sdf` 项**直接携带
梯度**（n̂ 已 `stop_gradient`），叠加 §9 给塑性求解器加的 `occupancy_override` 可微软占位
通道后，力学位移/残余应力对 SDF 的敏感性也能回传 → 整条"几何→成形"对 SDF 全可微。

### 11.2 实现（`src/amforge/inverse.py::optimize_shape`）
- 设计变量：名义 SDF 逐体素修正场 `delta`；在**归一化体素单位** `u = delta / spacing`
  上做 Adam，梯度量级被归一，避免米制单位下梯度过大/过小导致的发散。
- 热历史 `thermal` 由固定工艺**一次预计算**（不随名义几何微调重算）——增材反变形的
  标准假设：沉积热输入固定，仅名义几何改变力学响应位移场。
- 目标 = `w_geom·尺寸偏差 + w_stress·残余应力 + λ·光滑正则`，全部对 `u` 可微：
  - 尺寸偏差：`mean(|as-built.sdf − target.sdf| · soft_occ_target) / spacing`；
  - 残余应力：目标实体区体平均 von Mises / σ_y；
  - 光滑正则：归一化修正场 `u` 的总变差（TV）。
- 返回 `delta / nominal_geometry / asbuilt / loss_history / geom_history / stress_history`。

### 11.3 关键坑（已规避）
- **TV 正则的 0/0 梯度**：`jnp.linalg.norm(gu)`（=√Σgᵢ²）在平场（gu=0，u 初值为 0）处
  逆向导数为 0/0 → 整条梯度链 NaN，优化第 1 步即炸。改用 `sqrt(Σg² + ε)`（ε=1e-12），
  使导数处处良定义（`f'(gu)=gu/sqrt(Σg²+ε)`，gu=0 时为 0）。这是本次唯一阻断性 bug。
- **可微软占位 `occupancy_override`**：§9 已加，本次正式用于形状优化，使激活掩码/末态
  场回填对 SDF 可微（否则只有 `nominal_sdf` 直接项为梯度源，几何敏感性缺失）。

### 11.4 验证（3 项，全通过；实测收敛）
- `test_shape_gradient_finite_and_connected`：形状损失对 `u` 可微且梯度非零（几何→as-built
  链路连通）。
- `test_optimize_shape_reduces_dimensional_deviation`：16 步 Adam 后尺寸偏差较初始
  （delta=0 的 target 自身 as-built）**下降 2.4×**（5.51e-2 → 2.28e-2，残余 ~2.7 µm 量级，
  亚体素），补偿偏移最大 ~91 µm（~0.76 体素），补偿场与名义几何均有限。
- `test_optimize_shape_finite_results`：返回有限、物理合理；降阶 `buildup` 路径同样可跑
  （默认链路不受影响）。
- 全程 `pytest tests` 零回归。

## 12. 联合几何+工艺协同优化（反变形预补偿 + 工艺窗口同时调）
### 12.1 动机
§10 把设计变量定为**工艺参数** `z`，§11 把设计变量升级为**几何 SDF 修正场** `u`。
二者本质是同一条"残余尺寸偏差"目标的两条独立杠杆：

- `u`（形状）：预补偿名义几何，使 as-built 贴合 target；
- `z`（工艺）：调激光功率/扫描速度等，改变热历史→残余应力→尺寸偏差。

把它们**合并为一个可微目标**同步优化，即真正的**几何+工艺协同设计**：预补偿
形状与工艺窗口联合最小化残余偏差与失效风险，比任一单杠杆更优。

### 12.2 实现（`src/amforge/inverse.py::optimize_geometry_process`）
- 设计变量 pytree：`{"u": delta/spacing, "z": z∈[0,1]⁹}`。
  - `u` 仍归一化到体素单位做 Adam（梯度量级归一）；
  - `z` 归一化工艺向量，Adam 下自动满足设备边界（每步 `clip` 到 [0,1]）。
- **独立学习率**：用 `optax.multi_transform({"shape": adam(lr_u), "process": adam(lr_z)}, labels)`
  给形状/工艺各自 Adam 步长（两变量尺度/灵敏度差异大，共享 lr 易一臂失灵）。
- 物理前向（每步）：
  - 工艺 `z → ProcessPlan`；
  - **熔池/热历史由 target 几何 + 当前工艺决定**（见 §12.3 解耦理由），
    不随名义几何 `u` 重算热场；
  - 名义几何 `nominal = target.sdf + u·spacing` 经高保真塑性 FEM 成形
    （`occupancy_override = nominal.soft_occupancy`，激活掩码对 SDF 可微）；
  - 残余应力/应变、熔池缺陷、服役安全由 digitaltwin + verdict 评估。
- 目标 = `_dimensional_loss`(几何偏差+残余应力+残余应变+缺陷+安全罚) + `smoothness·TV(u)`，
  全部对 `u`、`z` 可微。返回 `delta / nominal_geometry / final_plan / asbuilt / z /
  loss_history / u_history / z_history / geom_history / stress_history`。

### 12.3 关键设计决策（避免回归/炸裂）
- **热历史与名义几何解耦**：`thermal(geometry=target, process=plan)` 用 **target**（具体数组）
  而非 nominal（tracer）。原因：(a) 增材反变形标准假设——沉积热输入由工艺主导，固定热
  载荷下搜索预补偿 SDF；(b) 若热历史依赖 nominal，则几何为 tracer 时其 `bbox()`/`sdf` 被
  numpy 构建网格会触发 `TracerArrayConversionError`（同 §10 jit 坑）。解耦后 `z` 改变时热场
  仍随 `plan` 重算（保证工艺窗口调参物理一致），`u` 改变时热场不变（仅力学响应变）。
- **TV 正则沿用 `sqrt(Σg² + ε)`**（§11.3），避免平场 0/0 梯度 NaN。
- 默认链路零改动：`optimize_geometry_process` 是独立函数入口，不注册进 ForgeCore 默认链
  路（避免 §9.6 的 modality→OOM 顶替问题）。

### 12.4 验证（3 项，全通过）
- `test_joint_co_optimization_reduces_deviation`：高能量工艺初值下，12 步协同优化使尺寸偏差
  降至初始 **<0.6×**；`delta` 与 `z` **均偏离初值**（两杠杆均连通、均生效）；`z∈[0,1]` 可行；
  as-built / nominal / final_plan 全部有限。
- `test_joint_both_levers_move_and_are_finite`：3 步即产生有限更新，损失下降，历史记录全有限、可行。
- `test_joint_competitive_with_shape_only`：联合优化（多一个工艺杠杆）的偏差下降比**不差于**
  纯形状优化（允许 15% 松弛，规避局部极小差异）。
- 全程 `pytest tests` 零回归。

## 13. 工艺杠杆物理约束 + 多目标 Pareto 协同优化

在上轮"联合几何+工艺协同优化（§12）"基础上，按用户需求新增两类能力：
**(a) 工艺杠杆物理约束**（把归一化工艺向量 `z` 推入真实物理可行域）；
**(b) 多目标 Pareto 协同优化**（在**尺寸偏差**与**残余应力**之间权衡）。

### 13.1 工艺杠杆物理约束（可微罚项）
新增 `process_constraint_penalty(z, ...)` 与 `process_feasibility(z, ...)`：
把 `z` 经 `denormalize_process` 还原为物理 `ProcessPlan`，对下列**物理耦合约束**
做软惩罚（全部 `relu`/比值形式，对 `z` 求梯度处处良定义）：

| 约束 | 表达式 | 物理意义 |
|---|---|---|
| 体能量密度窗口 | `E_v = P/(v·h·t)` ∈ [3e10, 1.5e11] J/m³ | 偏低→未熔合；偏高→匙孔/球化 |
| 道间搭接 | `h ≤ 0.9·w`，`w = 2r·sqrt(1+ΔH/h_s/8)` | 防止道间孔隙 |
| 层间结合 | `t ≤ 0.6·(2r)` | 防止层间未熔合 |
| 匙孔抑制 | `ΔH/h_s ≤ 30` | 抑制匙孔气孔 |

区别于既有"把 `z` clip 到 [0,1]"的设备标量边界，本罚项刻画**参数间的物理耦合**，
把工艺推入"致密且稳定"的真实可行域。接入 `optimize_dimensional` 与
`optimize_geometry_process` 的 `constraint_weight`（**默认 0.0**，保持旧行为零改动）；
置 >0 即在目标中注入约束罚项并回报 `constraint_penalty_history`。

### 13.2 多目标 Pareto 协同优化
新增 `pareto_optimize_geometry_process(target, ...)`：扫描权衡系数 `λ∈[0,1]`，对每个
`λ` 跑一次联合几何+工艺优化，目标标量化为

    L(λ) = λ·geom_dev + (1-λ)·stress_norm + smoothness·TV(u) + constraint_weight·penalty(z)

其中 `geom_dev` / `stress` 均已量纲归一化（量级相当）。复用 `§12` 抽出的共享辅助
`_joint_forward` 与 `_geom_stress_tv`，每个 `λ` 一次联合优化；返回：前沿
`(geom_dev, stress, constraint_penalty, feasible)`、各 `λ` 完整解、`utopia`
（两目标理论最优）与 `best_compromise`（目标空间归一化后离 utopia 最近者，L2）。
`λ=1` 偏尺寸精度、`λ=0` 偏低残余应力，中间给出折中前沿。

### 13.3 关键工程细节（坑与对策）
- **约束 details 禁止 `float()`**：`process_constraint_penalty` 在求导上下文被调用，
  其返回的 `details` 仅含 tracer 数组，**不调用 `float()`**（否则 Tracer→float 转换报错，
  同 §9.4）。`process_feasibility` / 报告在**求导外**取数。
- **共享前向抽离**：`_joint_forward` 从 `optimize_geometry_process` 抽出为模块级函数，
  行为**位级一致**（`constraint_weight=0` 时与原 `_forward` 完全相同）——既供 Pareto
  复用，又保证既有 3 项 joint 测试零回归。
- **Pareto 内 `loss_fn` 每 `λ` 构造一次、循环内复用**，避免逐步重编译（`jax.jit` 按函数对象缓存）。

### 13.4 验证（4 项新增，全通过）
- `test_process_constraint_penalty_finite_and_connected`：可行工艺罚≈0、病态工艺罚显著、梯度有限且非零。
- `test_process_constraint_reduces_penalty_in_joint`：启用约束后工艺罚显著低于未启用（同高能量初值）。
- `test_dimensional_constraint_keeps_plan_feasible`：约束后工艺可行（feas>0.5）且尺寸损失下降。
- `test_pareto_front_sweeps_and_stays_feasible`：前沿各点物理可行、目标有限、权衡发生、最优点可选。

**性能注记**：hifi CPFE FEM（`n_sub_cp=32, max_layers=4`）单步极慢（单 joint 测试实测
~203 s）。新增约束/Pareto 测试改用轻量参数 `_LIGHT = {n_grid=6, max_layers=3, n_sub_cp=8}`
缩短耗时，正确性不依赖高保真度；既有的重参数测试（11 项）保留原 `n_sub_cp=32` 配置。

## 14. 工艺杠杆硬投影（解析可行流形 Dykstra 投影）— 替代纯软罚项

**任务**：#36。把"软罚项"升级为**硬约束**——优化器每步把工艺向量 `z` 投影回物理
可行域最近点，从数学上保证最终工艺可行（而非仅压低罚项）。对应"高质量、不妥协"原则。

### 14.1 核心数学
在 **log 空间**对耦合工艺变量 `x=(ln P, ln v, ln t, ln h, ln r, ln A)` 构造**凸多面体**
可行域（全部为线性半空间，交集凸）：
- VED 窗口：`ln E_lo ≤ x_P − x_v − x_t − x_h ≤ ln E_hi`（VED=P/(v·h·t)）；
- 匙孔抑制：`x_A + x_P − 0.5 x_v − 1.5 x_r ≤ ln(keyhole_limit·ρ·cp·Tm·√(π α))`
  （ΔH/h_s = A·P/(ρcpTm√(π α v r³))）；
- 层间结合：`x_t − x_r ≤ ln(layer_factor·2)`（t ≤ 1.2 r）；
- 道间搭接（**保守充分** bound）：`x_h − x_r ≤ ln(overlap_factor·2)`（因 w≥2r，
  故 h≤1.8r ⇒ h≤0.9 w 必成立，保证**真可行**而非仅近似）；
- 各变量设备边界 box。

用 **Dykstra 算法**（box + 5 个半空间，6 个凸集，~60 次迭代）求 Euclidean(log 空间)
最近可行点：确定性、可微、`z` 全程保持具体（不 jit 外层几何）。其余 3 个线性变量
（preheat/powder_feed/dwell）不参与耦合约束，原样保留。

### 14.2 接入点（默认开启）
- 新增 `project_process_feasible(z, ...)`（inverse.py §7.5）。
- `optimize_dimensional` / `optimize_geometry_process` / `pareto_optimize_geometry_process`
  均新增 `hard_project: bool = True`（**默认开启**）。初始化与每个优化步 `apply_updates`
  后各投影一次 `z`。
- 软罚项 `constraint_weight` 保留为可选次级正则（默认 0）；既有的 2 项软约束测试
  显式 `hard_project=False` 以维持其原语义，不被默认行为改变。

### 14.3 验证（4 项新增，纯数学 2 项快、FEM 集成 2 项轻量参数）
- `test_hard_projection_is_feasible_idempotent_and_finite`：任意 z 投影后有限、∈[0,1]、

## 15. AM 专用枝晶相场求解器（micro.phasefield）— 缺口④高保真路径 + 接入逆问题

**任务**：#34。把"微观组织"缺口④从*统计代理*（`micro.surrogate`）升级为*逐晶粒相场演化*
的高保真路径 `micro.phasefield`，含**枝晶各向异性**与**热梯度取向（G 方向优先生长）**，
并接入 inverse/微观组织链路做可微评估（与任务②可微闭环同源）。

### 15.1 物理模型（Karma–Rappel 1996, PRL 77 4050 / PRE 53 R3017）
无量纲相场 φ∈[−1,1]（固=+1/液=−1）+ 过冷度 U，薄界面近似：
- 各向异性界面能 `a(θ)=1+ε₄·cos(N·(θ−θ₀))`，N=folds（立方金属取 4 重）；
  `<100>` 界面能最低 ⇒ 枝晶沿 `<100>` 主轴最快生长。
- 动力学各向异性 `θₖ(θ)=εₖ·cos(N·(θ−θ₀))`。
- **各向异性 → G 取向链条**：把主晶向 `θ₀` 设为热梯度方向 `atan2(G_y,G_x)`
  （代码中由 `gradient_axis` 代表：0→x、1→y），枝晶主轴即沿 G，体现"热梯度取向
  （G 方向优先生长）"。
- 含潜热过冷度演化 `∂U/∂t=D∇²U+½∂φ/∂t`，或定向凝固冻结线性梯度（沿 G）。

### 15.2 数值实现（旋转各向同性，根除 45° 网格偏置 ★关键）
- **谱（Fourier）导数** `spectral_grad/lap/div`（jnp.fft.fft2/ifft2）：旋转各向同性至
  机器精度。**致命坑**：5 点中心差分拉普拉斯是方形网格模板，界面失稳优先沿 45°，
  导致 4 重各向异性无论 ε₄ 正负、乃至 ε₄=0（各向同性）都 `arm/diag≈0.28` 偏对角。
  换谱导数后 θ₀=0 时 `arm/diag≈1.19`（轴优先），沿 +G 生长。
- 各向异性扩散用向量场散度 `∇·(a²∇φ)` 精确离散（自动含 `(∂ₐa²)(∂ₐφ)`），并补 Karma
  反对称校正项 `−½(∂ₐa²)(∂ₐφ)(1−φ²)`（恒等式消去奇点）。
- 纯 JAX、`jax.lax.scan` 推进（jit/grad 友好）。**时间格式默认半隐式 Fourier 谱
  （`semi_implicit=True`，见 §15.8）**：各向同性扩散 `∇²φ` 在 Fourier 空间作隐式求解
  （算子 `1/(1+dt·k²)`），各向异性涨落/反应/校正项显式。隐式吸收扩散刚性，支持大 λ
  （薄界面、定量 tip selection）下用大 dt 稳定推进。退回显式 Euler 用 `semi_implicit=False`。

### 15.8 半隐式 Fourier 谱格式 + λ 调大（本次迭代）
**动因**：用户指令"把 lam 调大并换半隐式时间格式"——薄界面（大 λ）是定量 tip selection
的前提，但显式 Euler 受扩散数 `dt<dx²/4` 与反应数 `dt<λτ₀` 双重限制，大 λ 下需极小 dt，
本机乃至 48G 都极慢且易失稳。

**改动（`src/amforge/phasefield.py`）**：
1. 新增 `_k2_grid(nx,ny,dx)` 返回平方波数 `k²=kx²+ky²`（隐式扩散算子所需）。
2. `DendriteConfig` 新增 `semi_implicit: bool=True` 字段（经 `tree_flatten/unflatten`
   透传，pytree 兼容）；`lam` 默认 2.0→**6.0**，`dt` 默认 0.1→**0.2**（半隐式允许更大步）。
3. 原 `step_phase_field` 改为**分发器**：`semi_implicit=True` → 新增
   `step_phase_field_semi_implicit`，`False` → `step_phase_field_explicit`（对照保留）。
   半隐式核心：把各向异性扩散 `∇·(a²∇φ)` 拆为各向同性 `∇²φ`（隐式，Fourier 空间
   `φ̂_new=(φ̂_old+dt·Ê)/(1+dt·k²)`）与各向异性涨落 `∇·(a²∇φ)−∇²φ`（显式）；反应项与
   Karma 反对称校正项显式。过冷度方程 `∂U/∂t=D∇²U+½∂φ/∂t` 对扩散隐式（`1/(1+dt·D·k²)`）、
   源项 `½∂φ/∂t` 用本步更新后 φ。**隐式扩散无条件稳定**，仅反应项仍受 `dt<λτ₀` 约束。
4. `solve_phasefield` 默认 `lam` 2.0→**6.0**、`dt` 0.1→**0.2**（与配置一致）。
5. 补充文档：模块顶"数值实现"段与 `DendriteConfig` docstring 注明半隐式默认、`bc` 字段
   在谱格式下本征为周期边界。

**阶跃收益**：半隐式对扩散刚性解耦后，大 λ（薄界面）可用大 dt 稳定推进——直接打通
"薄界面 → 定量 tip selection"路径，且仍全可微（Fourier 算子全 jnp、无具体化）。

### 16.4 FEM ↔ MBD 的耦合面（子模型边界法）
不是"把 FEM 网格塞进多体"，而是在**子模型边界**做刚度传递——这是工业界（ADAMS+Nastran、
Simpack+Abaqus）的标准做法，也是唯一能保持可微且不炸开自由度的做法：

1. **FEM → MBD**：`AsBuiltPart.displacement` 的范数 `‖u‖` 表征打印态畸变/残余变形，
   经共旋（corotational）折减给出关节抗弯刚度
   `K = (I/L)·10³ · 1/(1+50·‖u‖)`——畸变越大、关节越"软"。
2. **MBD → 耦合方程**：平面链广义质量阵闭式（等价 CRBA/Featherstone 复合刚体递推）
   `M_ij = Σ_{k≥max(i,j)} [ m_k (C_ki·C_kj) + I_k δ_ij ]`，重力广义力 `τ_g = −∂V/∂θ`。
3. **静力相容**：`Δ = K⁻¹ τ_g`（关节相对变形）。
4. **稳定性裕度**：`min eig(M⁻¹ diag(K))`——最低"结构频率²"，>0 即静定稳定；
   打印畸变→K 下降→裕度下降，物理链条闭合。

### 16.5 NVIDIA Newton：采纳结论与理由（用户授权"你决定"）
**调研事实**（2 次检索）：Apache 2.0、Linux Foundation 托管（NVIDIA + Disney Research +
Google DeepMind）；构建于 NVIDIA Warp + OpenUSD；内置 Featherstone / MuJoCo(Warp) /
XPBD / VBD / SemiImplicit / ImplicitMPM 等求解器；**可微**（正/反向）；支持
**求解器耦合**（如 MPM↔刚体）；可导入 URDF/MJCF/USD；**DLPack 零拷贝** Warp↔JAX/PyTorch；
MuJoCo-Warp 在 RTX 4090 上相对 MJX 报告 152×（locomotion）/313×（manipulation）。

**决定：采纳为"参考解 + 可选高性能后端"，不作为主可微路径。**
- 采纳的理由：现成求解器质量高、GPU 吞吐强、Apache 2.0 无授权风险，作为
  **oracle** 可零成本校验我们的 Featherstone 实现；作为后端可承接大规模非梯度仿真。
- 不作为主路径的理由：AMForge 逆问题链路是**纯 JAX**（`jax.grad`/`lax.scan` 端到端）。
  Newton 的计算图在 Warp 侧，若设为主路径，要么切断可微性，要么每步套
  `custom_vjp` + DLPack 跨框架搬运——**恰好牺牲权衡里的"速度"那一半**。
  因此把 Newton 放在 `mbd_fidelity="newton"` 这一档，用它的强项（吞吐/参考解），
  不用它的弱项（跨框架梯度缝合）。
- **工程形态**：`solve_mbd_newton()` 以 `try: import newton` 守卫，未安装抛
  `RuntimeError` 并给出安装指引；docstring 写明 48G Ubuntu 上的落地路径
  （`newton.create_articulation` → `SolverFeatherstone` → `ArticulationView` → `wp.to_jax()`）。
  本机（GTX 1650 Ti / 无 newton）跑守卫测试即可，不产生假绿。

### 17.5 关键 Bug 修复：颗粒热学单位错误（本次发现，真实缺陷）
三处 AM 热学更新（`step_dem_am` / `step_sph_am` / `step_mpm_am`）原写：
```python
dT = q_eff * dt / (am_state.mass * cp + 1e-30)   # ❌ 单位错误
```
`q` 是**体积热流** `[W/m³]`，与 `mass` 相乘缺颗粒体积因子，温度被放大
`1/V_p ≈ ρ·V/m ≈ 7e13×` 倍，MPM 跑 15 步即飙到 1.5e9 K → NaN（飞溅/剥蚀档炸裂）。
**修复**：给 `ParticleAMState` 新增 `rho: jax.Array` 字段（材料密度 [kg/m³]），热学更新改为
`dT = q_eff * dt / (am_state.rho * cp + 1e-30)`，单位正确（→ K）。

## 18. 多目标 NSGA-II 非支配排序替代 λ-标量化（Pareto 协同优化，#37）

### 18.1 动机：λ-标量化只能覆盖凸包
原 `pareto_optimize_geometry_process` 用 `L(λ)=λ·geom_dev+(1-λ)·stress` 在
`λ∈[0,1]` 上扫描生成"前沿"。但**加权求和只能得到 Pareto 前沿的凸包（convex hull）**：
一旦真实前沿出现**非凸段**（尺寸精度与残余应力此消彼长且存在权衡拐点），`λ`-扫描会
**系统性漏掉**凹段上的真实最优解，给出"伪前沿"。任务 #37 要求用**真 NSGA-II 非支配排序**
直接逼近真实（凸/非凸皆可）Pareto 前沿。

### 18.2 算法（与物理前向完全解耦）
新增 `src/amforge/nsga2.py`，纯数值、seed 可复现，含：
- `fast_non_dominated_sort(F)`：经典 O(m·N²) 非支配分层；
- `crowding_distance(F, front)`：层内沿各目标归一化相邻间距和，边界解给 `+∞` 保极端解；
- `sbx_crossover`：模拟二进制交叉（分布指数 `eta_c`）；
- `polynomial_mutation`：多项式变异（分布指数 `eta_m`，默认 `1/n_var`）；
- `crowded_binary_tournament`：先比非支配秩、再比拥挤度的二元锦标赛；
- `nsga2_minimize(objective, lb, ub, n_obj, config)`：主循环 = 变异生成子代 →
  父子合并(2N) → 非支配排序 → 按 (秩, 拥挤度) 截断回 N。

### 18.3 接入 `pareto_optimize_geometry_process`
- 新增 `algorithm` 参数：**默认 `"nsga2"`**；保留 `"lambda"` 作为 legacy 路径（用于回归/对比，
  本次重构后行为位级一致，由 `test_pareto_lambda_legacy_still_works` 守卫）。
- NSGA-II 搜索**联合设计空间** `x = concat(u_flat, z)`：`u` 为名义 SDF 修正场（体素单位，
  软边界 `±u_clip`），`z` 为归一化工艺向量（∈[0,1]⁹）。
- 新增 `pop_size / n_gen / eta_c / eta_m / p_crossover / p_mutation / seed / u_clip` 超参；
  `seed_with_lambda`（默认 `False`）用短 λ-扫描播种初始种群（混合 NSGA-II，仅初始化，
  排序仍为 NSGA-II）——加速原始场上 GA 收敛，生产推荐开启。
- 返回 dict 新增 `algorithm / pop_size / n_gen / population_geom_dev / population_stress /
  pareto_x`；`lambdas` 仅在 legacy 路径返回。两算法共享 `geom_dev/stress/feasible/plans/
  deltas/solutions/utopia/best_compromise` 键。

### 18.4 tracer-safe 约定
`_objective(x)` 在 **Python 循环**中逐个求值（不 jit），`x` 为**具体** numpy 数组，
`z` 经 `project_process_feasible` 硬投影保证可行——与 `_joint_forward` 的
tracer/numpy 混合物理前向完全兼容（无 `TracerArrayConversionError` 风险）。

### 18.5 测试
- `tests/test_nsga2.py`（**10 纯数值测试，~9s**）：非凸/凸前沿排序正确、拥挤度边界 `inf`、
  SBX/多项式变异不越界、一维双目标 `f1=x², f2=(x-2)²` 恢复真实前沿且**全部非支配**、
  同 seed 确定性复现、`init_pop` 规模正确。
- `tests/test_dimensional_optimization.py`：
  - `test_pareto_front_nsga2_non_dominated_and_feasible`：NSGA-II 前沿**必须非支配**
    （`fast_non_dominated_sort(front)[0]==全索引`）+ 全可行 + 权衡成立 + 最优点可选；
  - `test_pareto_lambda_legacy_still_works`：legacy 路径重构后回归。

### 18.6 验证

### 18.7 诚实尺度声明（精度/速度权衡）

- `algorithm="lambda"` 路径保留，便于与 NSGA-II 做前沿对比（凸问题两路应吻合，非凸问题
  NSGA-II 应补出凹段）。

### 25.3 判据 J3 的修订 + 未闭合缺口（不粉饰）
- **原判据本身写错了**：它把 **dx=r 档**（100µm 网格 + 100µm 光束，横向仅 2 个体素跨光斑）纳入"三档形态收敛"，等于要求一个已被本轮自己判定「熔池形态不可信」的网格通过形态判据。**修订**：形态与峰值判据只在 **dx ≤ r/2** 的档位上打；dx=r 档改为"警告是否兑现"的反例（实测熔宽 0.300 vs 0.550mm、熔体积 0.0460 vs 0.0715mm³，即 −45%/−36%）。
- **归因已做（P7/P8）**：dx=100 档的形态误差**不是时间欠采样**——步数乘到 4×（每步位移 79.5µm=0.80r → 19.9µm=0.20r）后 Ly 从 0.300 恢复到 0.400，但 nml/Lx/vol 完全不动；dx=50/25 档在时间上已收敛（P8）。所以粗档误差由**空间量化**主导，细档之间 1–2% 的峰值差是真实物理（蒸发封顶 + 界面 fv 加权），不是离散漏能。
- **仍未闭合**：细三档熔池几何以 **~4%/加倍** 漂移（Lx 6.38%、vol 7.73%，判据 5%），**A0 在形态维度上未做完**。机理：`T>T_liq 体素计数` 是阈值测度，对峰值幅度一阶敏感（exp(−2ρ²/r²) 上 3% 峰值差即约 4% 宽度差）＋界面体素量化。闭合手段是 **A3 外部基准数据**或 Richardson 外推，而不是继续调参数。
- **另一处耦合**：`c_evap=3.0e11` 自 2890K 介入，而细档峰值 2586–2670K 的**尾部**已进入封顶区，形态与封顶强耦合；A0b 需单独查这条（见 25.7）。

**新发现 T1：体素化对 dx 的浮点拼写敏感（1 ulp 改变层数）**
`_grid_axes`（`geometry.py:113-119`）用 `n = ceil((hi-lo)/spacing) + 1`。`dx_um * 1e-6` 与字面量 `{dx}e-6` 相差 **1 ulp**（`12.5*1e-6 = 1.2499999999999999e-05 < 1.25e-05`），当零件厚度恰为 dx 的整数倍时，`ceil` 就从 32 跳到 33 —— **同一零件、同一版本代码，仅参数拼写不同就多一层 Z 体素**（161602 vs 156849），峰值温度差 0.53%、熔化体积差 1.77%、熔化体素差 676。四档 dx 的 Z 层数是 5/9/17/33（字面量）vs 6/10/18/34（mul），X/Y 未受影响。
→ 这是 §25.3「空间量子化敏感性」的更尖锐版本：它发生在**夹具构造层**，不在度量层。任何跨档/跨探针的物理比较都必须先比 `sdf.shape`（v2 起每张表打印 nvox+shape）。
→ 待修 D4：`ceil((hi-lo)/spacing - 1e-9)` 一类的容差吸附，使 1-ulp 抖动不改变层数。

### 26.2 坐标系归一：本轮最隐蔽的一类 bug（症状是"绿不起来的可行度"）

公共 API 的 `z` **永远指设备盒归一化坐标**（`PROCESS_BOUNDS`），因为 `process_feasibility(z)` 一类外部调用者不知道档位存在。而 D0 引入的工艺子盒是**内部再参数化**。二者混用的后果是实测出来的：

- `optimize_dimensional` / `optimize_geometry_process` 直接返回子盒坐标的 `z` ⇒ 调用方用设备盒解读 ⇒ 物理值被放大几个量级 ⇒ `feas=3.7e-4 / 1.6e-4 / 9.7e-5`（三条测试同时红，罚项 ≈2700）。
- 修法：新增 `inverse.py:257 z_to_device_box()`（`denormalize(z, bounds=tier)` → `normalize(plan, bounds=device)`），在**四个返回位点**（`optimize_dimensional` 的 `"z"`、`optimize_geometry_process` 的 `"z"` 与每个 `z_history` 条目、NSGA-II 两处 decode）把坐标换回设备盒；内部（`joint_loss` 的罚项、Adam 状态、`final_plan` 的 denormize）一律保持子盒坐标。
- 一致性复查（本轮逐点看过）：`loss_fn` 从 `heuristic_plan` 钉档、`predict_process(..., bounds=tier_bounds(p))` 映射——同一张盒，自洽；`train_process_predictor` 原来用设备盒造 `final_plan` 而训练用子盒 ⇒ 出现 `exposure_bound_s=0.172s < 实际物理曝光 33.18s`（预测出的 v=0.0011 m/s 落在子盒下界之外），已改为**训练与终值同档**；`monitoring.py` 两侧都用 `bnds`，自洽；`solve_inverse_process`（随机权重、纯采样）有意留在设备盒。

**教训（可复用）**：凡是"内部再参数化 + 外部公共坐标"并存的地方，**返回位点必须逐个点名核对**，不能靠"看起来是对称的"。三条 feas 红就是只改了正向、忘了反向的账单。

### 26.10 三条红灯的根因：`√(Σg²)` 在 ∇T≡0 处的不可导点把反传打成 NaN（已定位，修正在验证中）
