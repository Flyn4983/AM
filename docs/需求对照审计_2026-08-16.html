① 宏观复杂几何增材成型模拟

子需求判定证据与缺口
真实三维复杂构型增材成型 满足 任意复杂几何 → SDF 体素化 → 分层 → 扫描路径（geometry.py、process.zigzag/contour/spiral/segments_from_gcode）； 高保真成形用体素 SDF 直接建 FEM 网格并反变形回填（asbuilt_plastic.py 生死单元 FEM，已测）。
SLM（选区熔融）+ LSF（激光立体成型） 满足 process.py 双模式：heuristic_plan 对 LSF 取粗而慢基准（line 237-241），PROCESS_BOUNDS 功率 20~4000W 同时覆盖两类设备； meltpool / thermal / enthalpy / mbd 的注册均 modality=("SLM","LSF")。
多物理场（热-流-力耦合） 满足 熔池 VOF 自由界面 CFD（动量 / Marangoni / 反冲压力 / 蒸发 / 糊状区 Darcy，meltpool.py 真实实现，meltpool.vof_flow3d）； 成形 FEM 残余应力（asbuilt_plastic.py）。物理链路完整。
固液 / 液固相变（潜热）
用户重点关切 ①		 满足 真实求解器存在且已测：thermal_enthalpy.py 的 thermal.enthalpy 用焓法 + 移动高斯热源 + 糊状区有效扩散系数 + SSP-RK2， 含潜热 L（line 201/243），test_enthalpy_thermal.py 6 passed（含“潜热降低峰值温度”）。
已修复（2026-08-16）：主可微链路 inverse.simulate() 现默认走真实焓法相变 thermal.enthalpy（thermal_solver="enthalpy" 为默认），并贯穿 loss_fn / optimize_dimensional / optimize_shape / optimize_geometry_process / pareto_optimize 等全部可微优化回路； Rosenthal 降阶模型保留为 thermal_solver="history" 供教学 / 快速回归。2D / 低维几何自动回退降阶（焓法仅实现 3D 体素场）。 冒烟验证：默认 simulate() 峰值温度 2212K > 失相线 1723K、time_above_melt>0，jax.grad 穿透无 NaN。
FVM / FEM / DEM / SPH / MPM 都要有 满足
集成部分		 diffmech/methods/ 下五法均真实实现：fvm/(thermal,stokes,advection)、fem/(linear,nonlinear)、 dem/dem.py、sph/sph.py、mpm/mpm.py。
已接入 AM 链路：FEM→asbuilt_plastic；FVM→thermal.enthalpy+熔池 VOF； DEM/SPH/MPM→粉末床尺度（simulate(...,powder_solver="dem"/"sph"/"mpm")）。
即“方法都要有”✅；但部件级默认链路主要用 FEM+FV+VOF，DEM/SPH/MPM 在粉末尺度与库级，非主链默认路径。

② 微观模拟（相场法 + 晶体塑性有限元 → 本构）

子需求判定证据与缺口
相场法（枝晶 / 组织演化） 满足 phasefield.py 真实 Karma–Rappel 枝晶相场：4 重界面能各向异性 + 热梯度取向（主轴沿 G）， 半隐式 Fourier 谱格式，micro.phasefield 已测（test_phasefield.py）。输出同 MicrostructureResult 契约。
晶体塑性有限元法（CPFE） 满足 diffmech/methods/cpfe/：CrystalPlasticity + fcc/bcc 滑移系；已接入 asbuilt_plastic(constitutive="cp") 与 constitutive.homogenize， 可产横观各向同性本构场。
工艺参数 → 本构模型映射 满足 链路闭环：工艺→热历史→微观（相场/代理）→constitutive.homogenize（Hall-Petch 屈服 + 孔隙 Mori-Tanaka 折减 + Hill48 各向异性，constitutive.py）。 下游 asbuilt / digitaltwin 直接消费本构场。

③ 数字样机（FEM + 多体 + 强度校核）

子需求判定证据与缺口
FEM + 多体动力学耦合 满足 mbd.py + diffmech/methods/mbd/：surrogate / coupled(JAX Featherstone+FEM 关节柔度) / newton(Warp 生产级) 三档； digitaltwin.rom 给服役应力下的位移与应力集中。
以本构模型做强度校核 满足 verdict.py 用 constitutive.effective_stiffness() + 孔隙应力集中 Kt + 强度/刚度/疲劳/磨损安全系数；已接入主链。
默认链路保真度 部分满足 默认 mbd_solver="surrogate"、digitaltwin.rom 为降阶；真实 coupled/newton 需显式选， 且 newton 路径本机抛错（需 48G Ubuntu，见 #38）。能力齐，默认非高保真。

④ 可微分模拟 → 工艺优化

子需求判定证据与缺口
